# Storista

A startup landing page project. Currently a static site (HTML/CSS/JS) — no build step, no framework.

## Structure

- `index.html` — landing page markup (hero, features, pricing, CTA, footer)
- `styles.css` — all styling, dark theme with gradient accents
- `app.js` — waitlist form handling (localStorage), smooth-scroll for in-page links

## Running locally

Just open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
# or
python -m http.server 8000
```
